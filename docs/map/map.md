# map

The city map: one object built through five inheritance levels (tiles, objects, people, render, city map; vtables
at `+100`: `0x1BCEF0` objects, `0x1BCEE0` people, `0x1BCF00` render, `0x1BCED0` city map).

| Offset | Meaning |
|---|---|
| `+4` | tiles: 128 x 128 entries of 0x18 bytes (`+0` height, `+4` .. `+0x10` vertex data, `+0x14` first object, `+0x16` flags) |
| `+8` | objects (buildings): 0x1C bytes each: `+0` type, `+4` tile (x = low 7 bits, z = bits 7+), `+6` flags, `+8` first person, `+0xC` family, `+0x12` claim slot |
| `+0xC` | tile lists |
| `+0x68` | people: 6000 records of 0x30 bytes (layout in `char`); 6000 means none |
| `+0x74` | population |
| `+0x2F60` | render layers (`gfx`) |

`0x3F80` means no object. Terrain (`mm_Terrain*`, generated by `mm_TerrainGen_*`), vertex buffers (`mm_MapVerts_*`),
placement checks (`mm_Placement_*`) and the per-object history (`mm_MapObj_*`) are here too.
